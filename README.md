# SprachenLernen

Apps, die dich beim Lernen von Sprachen unterstützen. Die Inhalte sind erweiterbar.

## Frenchie – le chien qui lit

Französisch mit eigenen Texten lernen, für iPhone und iPad ab iOS/iPadOS 17. Karteikarten in beiden Sprachrichtungen, Lautschrift, Sprachausgabe und Import eigener XLSX-/CSV-Dateien. Die Bibliothek startet leer; Bücher 2 und 3 werden nicht mitgeliefert.

**[IPA und Quellcode herunterladen](https://github.com/jgruhl-sw/SprachenLernen/releases/tag/frenchie-1.0-3)**

Die Veröffentlichung erfolgt für **AltStore Classic mit AltServer**. Lade die IPA auf dein Gerät und importiere sie in AltStore Classic unter „My Apps“ über das Plus. AltStore übernimmt die Signierung mit deinem eigenen Apple-Account. Eine Anleitung zum Einrichten bietet die [offizielle AltStore-Dokumentation](https://faq.altstore.io/altstore-classic/how-to-install-altstore-macos).

AltStore-Quelle:

https://github.com/jgruhl-sw/SprachenLernen/releases/download/frenchie-1.0-3/altstore.json

`Frenchie-Source-1.0-3.zip` enthält das vollständige Xcode-Projekt, die Bauanleitung, ein Skript zur IPA-Erstellung, eine leere Importvorlage und die GPL-3.0-Lizenz. Die IPA enthält keine Entwicklerzertifikate oder Provisioning-Profile.

Der Release-Build wurde mit Xcode erstellt und technisch auf Paketstruktur und leere Bibliothek geprüft. Eine Installation dieser IPA über AltStore auf einem echten Gerät wurde nicht geprüft.
